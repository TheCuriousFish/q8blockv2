# Blog Image Generation Guide

Use these prompts to generate consistent blog post images for Q8Block.

## Style Template
All blog images follow this pattern:

```
Minimalist flat illustration of [SUBJECT RELATED TO BLOG TOPIC] on/with [SETTING OR CONTEXT]. [PRIMARY COLOR] and dark navy color palette. No people, no text, no faces. Clean digital [INDUSTRY] concept art. Abstract and modern.
```

## Color Palette by Category
- **Local SEO**: Teal (`#1a8a9e`) and dark navy
- **Google Business Profile**: Blue (`#4285F4`) and dark navy
- **Strategy / Analytics**: Green (`#22C55E`) and dark navy
- **General / Other**: Use brand teal (`#BCE1EC`) and dark navy

## Rules
1. Always use "Minimalist flat illustration" as the style prefix
2. Always include "No people, no text, no faces"
3. Always end with "Abstract and modern"
4. Keep dark navy as a constant secondary color
5. Match the primary color to the blog category (see palette above)
6. Subject should visually represent the blog topic without being literal
