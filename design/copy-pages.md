frontmatter shape used by the six blog posts in `content/blog/`.

## The rules this file is written under

Every rule in `copy.md` applies here unchanged. The four that decide the most sentences:

1. **Headlines eight words or fewer. No dashes anywhere. No emojis anywhere.**
2. **Two CTA labels only**, `اتصل الآن` / `Call now` and `واتساب` / `WhatsApp`. A text link such as
   `اقرأ المقال` / `Read the article` is navigation, never a third button label.
3. **No invented facts.** No prices, no durations, no headcount, no founding date, no licence number,
   no statistics, no client testimonials. If a claim is not in `company.md` or `copy.md`, it is not here.
4. **`rank` is not a selling word**, and neither are `ترتيب`, `يتصدر`, `نتصدر`. The register everywhere is
   being **found** and being **discovered**, on Google and in AI answers, and the calls that follow.

Three more that are specific to these pages:

5. **No figures on any of these four pages.** Every performance figure on this site lives in homepage
   Sections 6 and 7. These pages point at that section by name; they never reprint a number from it.
6. **No geography.** Same carve out as the homepage footer: the company's own address is NAP from
   `company.md`, not positioning, so it appears on Contact and on About and nowhere else. Saudi Arabia
   stays on `/offer` alone, because it is a condition of that one promotion.
7. **There is no team and no founder story.** The company writes as the company. No `our team`, no
   `our experts`, no `our people`, no `since 20XX`, and Ahmad's face is not on any page. The one place a
   person is named is the blog byline, which is a real author credit.

## What could not be written, and why

Recorded so the next agent does not try to fill these gaps with something invented.

* **A licence or registration number on About.** `lessons.md` says the About page uses real facts including
  the licence. `company.md` holds the registered name only, so About names `شركة كويت بلوك` / `Kuwait Block`
  and stops there. If Ahmad supplies a CR number it drops into the company block in one edit.
* **Office hours on Contact.** Not in `company.md`. The office block gives the address and nothing else.
* **`بدون عقد` / `No contract` on Terms.** It is an offer term from `copy.md` B4 and nobody has confirmed it
  is true of Q8Block outside the promotion. The same question was already resolved the safe way in the
  homepage trust row. Terms therefore points at `/offer` for it and states nothing itself.
* **Anything about what happens if either side stops, beyond the offer page.** No notice period, no refund
  policy, no liability wording, no jurisdiction. Terms says plainly that those are agreed directly.

### The three overrides, and what they cost

1. **Category chips are allowed on this page.** The rule above used to read *"No category chips, no
   tags"* and build-spec §18.5.2 D left the board's `SEO` label undrawn for exactly that reason. Ahmad
   overruled it. Every post now carries a `category` in frontmatter; only the featured panel renders it.
2. **The byline and the read time leave the list page.** Both still appear on every post page (§B3), so
   the author link to `https://ahmadowaihan.com/` is not lost from the site — only from this one page,
   where the board has no room drawn for it. There is now **no outbound link on the list page.**
3. **`Read more` replaces `Read the article` / `اقرأ المقال`,** because that is what the board draws,
   and it takes an arrow rather than the site's `›` chevron.

**Build rules for the card.**
* Dates render as the day, the month name and the year in the page's own language, matching the
  `24 سبتمبر 2026` / `24 September 2026` form already used in the homepage source caption. English
  uppercases and tracks it the way the board draws it; Arabic takes neither (no case, and tracking
  breaks joined letterforms).
* **The board's own dates are not used.** It draws `APR 12, 2025` and similar, which are model
  inventions. The real publication date is printed. Ahmad: *"I want to be honest and no fake."* Only
  the treatment is the board's.
* The six posts all carry the same publication date, because they are the launch set and dating them
  apart would invent a publishing history the site does not have. If Ahmad wants them staggered, the
  dates are one edit each in frontmatter.
* Excerpts are written to the line count the board draws — two lines on a row, three on the featured
  panel — at the built column widths. That is a copy constraint, not a CSS one: an excerpt that runs
  long adds a line to its row and the list stops matching the board.

## B5. Blog post frontmatter

No `content/` directory existed in this repo before these six posts, so the shape is defined here. It is
the shape the sibling client repos already use (`title`, `description`, `excerpt`, `read`) plus the four
fields this site's blog list and post template need.

```yaml
---
title: the post title, eight words or fewer
description: the meta description, one or two sentences
excerpt: one line for the card, different from the description
category: SEO
date: 2026-09-24
author: Ahmad Owaihan
authorUrl: https://ahmadowaihan.com/
slug: kebab-case-english-slug-identical-in-both-languages
lang: ar
read: 5
---
```

| Field | Rule |
|---|---|
| `title` | Eight words or fewer. No dashes, no emojis. **The six launch titles are taken off `blog-B.png` exactly as it draws them** (2026-09-25, below), which is why they are in Title Case and use SEO vocabulary; that is deliberate and Ahmad's instruction, not drift. Anything written after them goes back to sentence case. |
| `description` | For the `<meta name="description">` of the post page. Never identical to the excerpt. |
